================================================================================
A股自选股智能分析系统 - 详细使用步骤
================================================================================

这是一个基于 AI 大模型的自动化股票分析系统，支持 A股/港股/美股。
以下是详细的使用步骤。

================================================================================
一、快速开始（推荐）- GitHub Actions 方式（0成本，无需服务器）
================================================================================

【步骤1：Fork 仓库】
1. 访问项目地址：https://github.com/ZhuLinsen/daily_stock_analysis
2. 点击右上角"Fork"按钮，复制到你的 GitHub 账户

【步骤2：配置 Secrets（关键步骤）】

进入你 Fork 的仓库 → Settings → Secrets and variables → Actions → New repository secret

必配项：

配置项                      来源                          用途
GEMINI_API_KEY（推荐）      Google AI Studio              免费 AI 大模型，用于分析
STOCK_LIST                  自己设置                      你的自选股，格式：600519,300750,002594
TAVILY_API_KEYS             Tavily                        股票新闻搜索（每月1000次免费）


可选渠道配置（选至少1个推送方式）：

- 企业微信：WECHAT_WEBHOOK_URL（最方便）
- 飞书：FEISHU_WEBHOOK_URL
- Telegram：TELEGRAM_BOT_TOKEN + TELEGRAM_CHAT_ID
- 邮箱：EMAIL_SENDER + EMAIL_PASSWORD + EMAIL_RECEIVERS

【步骤3：启用 Workflows】

1. 进入仓库的 Actions 标签
2. 点击"I understand my workflows, go ahead and enable them"
3. 选中"每日股票分析" workflow

【步骤4：手动运行测试】

1. 进入 Actions → 每日股票分析
2. 点击"Run workflow"按钮手动执行
3. 等待运行完成（通常5分钟左右），检查结果

【步骤5：完成！】

✅ 已默认配置每天 08:00 和 17:00（北京时间）自动执行
✅ 分析结果会推送到你配置的渠道（企业微信/邮箱等）

================================================================================
二、本地运行方式（用于开发测试）
================================================================================

【步骤1：环境准备】

# 1. 克隆项目
git clone https://github.com/YOUR_USERNAME/daily_stock_analysis.git
cd daily_stock_analysis

# 2. 创建 Python 虚拟环境（3.10+）
python3 -m venv venv
source venv/bin/activate  # macOS/Linux
# 或 venv\Scripts\activate  # Windows

# 3. 安装依赖
pip install -r requirements.txt

【步骤2：配置 .env 文件】

在项目根目录创建 .env 文件：

---开始复制---
# AI 模型配置（三选一）
GEMINI_API_KEY=your_gemini_api_key
# 或
# OPENAI_API_KEY=your_openai_api_key
# OPENAI_BASE_URL=https://api.deepseek.com/v1
# OPENAI_MODEL=deepseek-chat

# 自选股列表（关键！）
STOCK_LIST=600519,300750,002594

# 新闻搜索 API
TAVILY_API_KEYS=your_tavily_api_key

# 推送渠道（至少选一个）
WECHAT_WEBHOOK_URL=your_wechat_webhook_url
# 或
# FEISHU_WEBHOOK_URL=your_feishu_webhook_url
# TELEGRAM_BOT_TOKEN=your_telegram_token
# TELEGRAM_CHAT_ID=your_chat_id
---结束复制---

【步骤3：运行分析】

# 正常运行
python main.py

# 调试模式
python main.py --debug

# 仅获取数据不分析
python main.py --dry-run

三、分析系统做了什么
================================================================================

系统会为每只自选股生成"决策仪表盘"，包括：

分析维度              内容                              示例
一句话结论            核心投资逻辑                      强势上升趋势，可继续持有
精确买卖点            买入价、止损价、目标价            买入：11.5元 / 止损：11.0元 / 目标：12.5元
技术面分析            MA5/MA10/MA20 多头 / 量能确认    ✅ 满足 / ⚠ 注意 / ❌ 不满足
筹码分析              主力持仓集中度、MACD 状态        筹码集中度 78%
新闻情报              实时股票新闻、业绩预期           最新3天内相关新闻
操作检查清单          买入前的风险检查                 乖离率检查、追高风险提示

五、核心配置说明
================================================================================

配置项                        说明                                          默认值

六、常见问题
================================================================================

【Q1：没有 API KEY 怎么办？】
- Gemini：免费，无需付费，推荐使用
- OpenAI：可用 DeepSeek（更便宜）或本地 Ollama

【Q2：GitHub Actions 运行失败？】
- 检查 Secrets 是否正确配置
- 检查 STOCK_LIST 格式（逗号分隔）
- 查看 Actions 日志获取错误详情

【Q3：推送不到企业微信？】
- 检查 Webhook URL 是否正确
- 确认企业微信客户端已安装

【Q4：如何修改分析时间？】
- GitHub Actions：编辑 .github/workflows/ 中的 cron 时间表
- 本地：用 schedule 库设置定时任务
